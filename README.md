## Project Overview

**DualShift** is a 2D puzzle-platformer focused on **asymmetric cooperation**. The player controls two interchangeable characters, each with a distinct ability. To overcome challenges, you must switch control between them, using the agility of one and the strength of the other to unlock the path to the exit.

### Key Features
* **Instant Swap:** Change characters in real-time to solve dynamic situations.
* **Forced Cooperation:** Both characters physically exist in the level; you must use both to complete each stage.
* **Pure Mechanics:** Based on weight, height, and mechanism activation.
* **Minimalist Aesthetic:** Clean red and blue design for a clear reading of puzzles and abilities.

### The Protagonists
Both characters share basic physics but excel in their primary skill.

| Basic Skill | Character | Special Skill | Physical Attribute |
| :--- | :--- | :--- | :--- |
| **Agile** | Lulu (Dog) | **High Jump** | Reaches high platforms |
| **Strong** | Wilson (Cat) | **Heavy Push** | Moves blocks & activates weight plates |

---

## Level Structure (4 Levels)
The game consists of 4 short levels designed to teach and challenge player logic:

| Level | Title | Theme / Objective |
| :--- | :--- | :--- |
| **1** | **The Awakening** | Tutorial on movement and the swapping system. |
| **2** | **Mass & Volume** | Introduction to pushing blocks with the Red Character. |
| **3** | **The Sacrifice** | Using buttons where one character must stay behind to help the other. |
| **4** | **Sync or Sink** | Final integration of all mechanics in a complex puzzle. |

## Controls

| Action | Key |
| :--- | :--- |
| Move | `A` - `D` / `Arrows` |
| Jump | `Space` / `W` |
| **Swap Character** | **`Tab` / `Q`** |
| Interact | `E` |
| Reset Level | `R` |

## Tech Specs & Roadmap
* **Art Style:** Minimalist Pixel Art (High Contrast).
* **Engine:** Godot.
* **Development Sprint:** 4 Days.

### 4-Day Development Plan
1. **Day 1 – Base Movement:** Physics, character creation, and the swap system.
2. **Day 2 – Mechanics:** Pushable blocks, buttons, and doors.
3. **Day 3 – Level Design:** Creating the 4 levels and adjusting difficulty.
4. **Day 4 – Polish:** Basic sound, simple animations, and UI.
